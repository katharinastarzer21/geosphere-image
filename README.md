# geosphere-image

Container image for the SPARTACUS/INCA Argo CronWorkflows defined in
[geosphere-zarr-workflows](https://git.eodc.eu/eodc/mission/access/playground/geosphere-zarr-workflows)
(python + xarray/zarr/numpy/pandas/netCDF4, pinned exact versions).

Push to `main` (touching `Dockerfile`/`requirements.txt`) to rebuild and push
`ghcr.io/katharinastarzer21/geosphere-image:latest`.
